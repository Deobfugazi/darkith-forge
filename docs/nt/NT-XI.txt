PART I — THE DERIVATION

§2 — The Five Premises

P1 — No module rebuilds a shipping substrate. A substrate is shipping if a working implementation or a published conformance spec with a running reference exists.

P2 — Every module has a prior-art anchor or is explicitly BUILD. A BUILD module must have no prior art as a protocol-level predicate. An ADOPT/ADAPT module must name the substrate it wraps and state its delta.

P3 — Every module ships a falsifier. A falsifier is a single runnable command that fails loudly (non-zero exit) when the module's invariants are violated.

P4 — Check-time dependencies only; no runtime dependencies. No module imports another at runtime. The dependency graph among modules is a DAG at check time.

P5 — The composition is a check-time equivalence, not a runtime. The composition is integrates(profile, unit_conformance, candidate, frozen_team_context) → Admit | Refuse. It is a function. It retains no state across calls.

These five premises are the axioms.

§6 — Step 4: Apply P5 to Force the Composition

The three specifications meet at check time. This requires exactly one predicate that reads each specification's output.

integrates(profile, unit_conformance, candidate, frozen_team_context) → Admit | Refuse

The composition is not a seventh module. It has no interface of its own, no invariants of its own, no lifecycle of its own. It has a falsifier command (compose.falsify) that runs the conjunction of the six modules' falsifiers plus the vocabulary-table check — but having a falsifier command does not make it a module; it makes it a composition predicate whose correctness is the conjunction of its inputs' correctness plus the vocabulary check. The distinction is: modules have state or lifecycle; the composition has neither.

The eight behavioral checks:

§15 — M6: SE Five-Clause Predicate

Prior-art anchor: Web4 (4/5), E54 (4/5), ICN ADR-0012 (origin), EY COO tokens.

Delta (BUILD): Clause 5 — state_snapshot() == ∅ before/after every call — as checked invariant; five clauses as one predicate.

Interface:

```typescript
interface SEModule {
  readonly module_id: "M6";
  readonly version: string;
  standalone(input: SEInput): Promise<AdmissionResult>;
  attach(substrateA: SubstratePort, substrateB: SubstratePort): AttachedSE;
  falsify(input: SEFalsifierInput): Promise<FalsifierResult>;
  readonly prior_art: ReadonlyArray<PriorArtCitation>;
}

interface AttachedSE {
  admits(exchange: Exchange): Promise<Admit | Refuse>;
  state_snapshot(): ReadonlySet<ExchangeId>;
}
```

The Five Clauses:

1. Origin preserved. exchange.origin_token == substrateA.get_origin_token(exchange.source_entry_id), AND substrateB.get_origin_token_after(exchange.value) == exchange.origin_token.
2. Non-extractive for A. substrateA.get_retention_ratio().after ≤ before.
3. Non-extractive for B. Symmetric.
4. Symmetric sovereignty. substrateA.get_external_dependencies().after ⊆ before; same for B.
5. No retained state. state_snapshot() == ∅ before/after each call.

SE statelessness mechanism (frozen):

The engine's only state is Set<ExchangeId> of currently-open exchanges. Per admits(exchange, A, B):

1. Before: exchange.id ∉ state.
2. record_exchange_open(exchange.id).
3. Evaluate all five clauses. Origin tokens and retention ratios read via adapters — never cached.
4. If any clause fails: record_exchange_close(exchange.id), return Refuse(clause).
5. If all pass: record_exchange_close(exchange.id), return Admit.
6. After: state_snapshot() equals pre-call state.

The engine has exactly three instance fields: adapter_a, adapter_b, open_exchanges.

Invariants:

· I-M6-1: All five clauses must pass. No partial admission.
· I-M6-2: Engine fields = adapter_a, adapter_b, open_exchanges only.
· I-M6-3: Origin tokens read per-call, never cached.
· I-M6-4: state_snapshot() before/after each call does not contain the exchange's ID.
· I-M6-5: Retention ratios read per-call, never cached.
· I-M6-6: No federation-level aggregates.

Refusals: ORIGIN_MISMATCH, EXTRACTIVE_FOR_A, EXTRACTIVE_FOR_B, A_BECOMES_DEPENDENT, B_BECOMES_DEPENDENT, ENGINE_RETAINS_STATE.

§16 — The Composition Predicate

Not a seventh module (P5). It has no interface of its own, no invariants of its own, no lifecycle of its own. It has a falsifier command (compose.falsify) that runs the conjunction of the six modules' falsifiers plus the vocabulary-table check. Having a falsifier command does not make it a module; the distinction is: modules have state or lifecycle; the composition has neither.

Body (exact):

```typescript
function integrates(profile, unit_conformance, candidate, frozen_team_context) {
  // 1. NT XI conformance (M2 + M3 + M4 + M5 + adapter checks)
  if (!unit_conformance.is_ntxi_conformant) return Refuse("unit_not_conformant");

  // 2. Floor conformance — reads S3 via unit_conformance (corrects v1.0/v1.1 defect)
  if (!unit_conformance.floor_conformance.is_conformant) return Refuse("floor_not_conformant");

  // 3. AQP conformance (M1)
  if (!is_aqp_conformant(profile, candidate, frozen_team_context))
    return Refuse("profile_not_conformant");

  // 4. Every ADMITTED principle maps to a UNIT_CLASS
  for (const p of profile.principles.filter(p => p.verdict === "ADMITTED")) {
    if (!vocabulary_maps(p, UNIT_CLASSES)) return Refuse(`principle_unmapped:${p.principle_id}`);
  }

  // 5. Every required need with no DIRECT fit is in not_qualified
  const required = frozen_team_context.needs.filter(n => n.required).map(n => n.need_id);
  const direct = profile.fits.filter(f => f.fit === "DIRECT").map(f => f.need_id);
  const nq = profile.not_qualified.map(e => e.need_id);
  for (const need of required) {
    if (!direct.includes(need) && !nq.includes(need)) return Refuse(`need_unaccounted:${need}`);
  }

  return Admit("integrated");
}
```

· I-C-4: Admit only if all five checks pass.
