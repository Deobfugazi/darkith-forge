Grammar & Engine Notes

Native Claim Grammar

  • assume ID — declares an axiom
  • ID derives from ID1, ID2 — derivation (parents must resolve)
  • EXPR equals EXPR — arithmetic identity (no x)
  • d/dx of EXPR at N is N — symbolic derivative
  • The integral of EXPR from A to B is N — Simpson's rule
  • The exponential of N is N, The logarithm base B of X is N
  • the sine|cosine|tangent of N is N
  • The determinant of [[a,b],[c,d]] is N
  • The capital of France is Paris — fact lookup
  • The row|column|depth axis traverses DIR on the CHART chart
  • 3 meters plus 2 meters equals 5 meters — dimensional arithmetic
  • The sequence [A, B] violates the invariant NAME
  • The operation A precedes B

Gates

Every claim maps to one phiN gate. Gates marked HARD (phi2–5, phi7–12) turn a failure into LIED. SOFT gates (phi0, phi1, phi6) yield BLOCKED instead.

Code Scan Mode (Load Grammar)

Switch the audit sub-language to Solidity/Rust/Python/JavaScript/Go/C++/Cairo/Move and click Load Grammar. Everything runs offline — no downloads. Paste raw code into the editor and press Run; the built-in structural scanner flags external calls without access control and functions that mix external calls with state updates (reentrancy).

Theme & Buttons

Theme (top bar, or Ctrl+J) cycles Auto → Light → Dark; Auto follows your OS. Buttons opens the configurator: choose which commands appear in the bottom belt and the floating quick-action column, reorder them, and reset to defaults. Your layout and theme persist.

Payloads

Facts, constants, rules, units, invariants. Built-in defaults ship with the engine; loaded payloads merge into them and are tagged in the Payload inspector. The .savf.json file you save into the Memory Pool can be re-loaded as a payload by pressing the Payload… action or via drop.

Keyboard

  • Ctrl+Enter — run audit (AUDIT mode)
  • Ctrl+S — save to pool
  • Ctrl+K — toggle payload inspector
  • Ctrl+. — apply first available fix
  • F8 / Shift+F8 — jump to next / previous fail
  • Ctrl+F — find
  • Ctrl+/ — toggle comment
  • Ctrl+L — clear editor
  • Ctrl+J — cycle theme (auto / light / dark)
